# DaySpark 

DaySpark is a productivity app built with Flutter and Serverpod that helps users organize daily tasks, set priorities, track progress, and build consistent habits.

## Features
- **Task Management:** Add, edit, delete, and complete daily tasks.
- **Spark Start:** Break tasks into manageable steps and get started.
- **Goal Tracking:** Stay focused on personal goals.
- **Day Replay:** Reflect on daily progress.
- **Progress Tracking:** Monitor task completion and productivity.

## Tech Stack
- **Frontend:** Flutter, Dart
- **Backend:** Serverpod
- **Database:** PostgreSQL
- **Tools:** Git, GitHub, Docker

## Getting Started
1. Clone this repository.
2. Start Docker Desktop if your backend services require it.
3. Start the Serverpod backend using `serverpod start`.
4. Navigate to the Flutter project directory.
5. Run `flutter pub get`.
6. Launch the app using `flutter run`.

## Purpose
DaySpark aims to make productivity simpler by helping users take small, meaningful steps toward their goals.
